What it does

The whole meeting, handled locally.

Recording, transcription, clean-up, and summaries — one native app, no services to sign up for.

Mic + system audio

Captures your microphone and everything the Mac plays, mixed with per-channel gain and soft limiting. Live level meters, pause and resume.

Live transcription

whisper.cpp and Parakeet running on Metal, transcribing in silence-aligned chunks while you record. 99 languages, plus translate-to-English.

Transcript clean-up

One click turns raw timestamped output into readable paragraphs with topic headings — filler removed, timecodes preserved. Raw stays a toggle away.

Summaries, open models

Ollama by default, or any self-hosted OpenAI-compatible endpoint — llama.cpp, vLLM, LM Studio, LocalAI. Long transcripts are map-reduce chunked.

A searchable library

Every meeting stored in local SQLite with per-meeting notes, full-text search, Markdown export, and copy-to-clipboard.

Import & re-transcribe

Drop in any audio file, or re-run an existing recording through a different model when you want a better pass.

Privacy

Nothing leaves your Mac.

Wffl was built local-first, not local-optional. Audio, transcripts, and summaries stay in your own file system, and the app works with the network off.

No account

Nothing to sign up for, nothing to log in to. Download it and record.

On-device models

Whisper and Parakeet run on your GPU. Summaries default to a model on your own machine.

Cloud is opt-in

Hosted providers are strictly optional and off by default. Keys live in the macOS Keychain.

First run

Three steps, then it's yours.

The download is small. Models are fetched once from inside the app, so you choose what lands on disk.

1

Install the app

Open the DMG and drag Wffl into Applications. Signed and notarized, so it opens normally.

2

Download a speech model

Settings → Transcription. Start with base.en; large-v3-turbo for best quality. A few hundred MB to a few GB, one time.

3

Add a local LLM

Install Ollama and pull a model for summaries and clean-up. Optional — recording and transcription work without it.

Full details in the setup guide.
