# Setup study (first-run setup)

Scope: native SwiftUI study of first-run setup (model download, microphone, system audio). Mode: Operate, with the brief pinning the opening film's cinematic motion. Audience: new and updating Wffl users on a Mac. Task: download BAPS Whisper (about 1.6 GB), allow microphone, optionally allow system audio, then arrive in Ask. States: download progress, paused, failed and retry; microphone and system audio denied; set up later. Downloads and permissions are simulated in the study.
